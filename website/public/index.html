Precise speed. Updates made easy.

Dial in the exact pace with a continuous 0.25×–4× speed slider, or return to normal with 1×. The free direct-download edition now includes optional updates powered by Sparkle.

  • Opt in to daily update checks, or use LocalioBC → Check for Updates… whenever you choose.
  • Automatic downloads are optional. Installation waits during exports and asks before discarding open session edits.
  • The Mac App Store edition receives its updates through Apple.

Using 1.1.0 or earlier? Download and install the latest version once manually. Those versions have no built-in updater; you can receive later updates directly in the app.

Your video, at your pace.

Slow down an important moment or speed up a longer shot. Set each clip’s speed from 0.25× to 4×, right beside the playback controls.

  • The same speed in the preview and exported video.
  • Picture and sound stay in sync; audio pitch changes with speed.
  • Output duration and estimated file size update as you edit.
