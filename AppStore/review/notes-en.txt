LocalioBC 1.3.0 (10) is a simple, quick video-cropping utility for macOS. This is a one-time paid Mac App Store purchase (EUR 4.99 in the selected euro storefront), with no app subscription, in-app purchase, app account or analytics. The MIT license is bundled and available in About. Sparkle and all updater helpers are physically excluded; Store updates are handled by Apple.

No sign-in or demo account is needed for import, editing, previews or local export. These functions work offline. Version 1.3.0 adds an optional client for the user's own Bunny Storage account; it does not create a Localio Labs account or send media through our servers. Bunny Storage and CDN usage are separate services billed by Bunny.net to that user. The app does not charge an upload fee or unlock editing features through Bunny signup. The labelled affiliate signup link opens in the external default browser with the same public referral code for every user, without app/device identifiers, click telemetry, browser SDKs or embedded web views. Registration and billing take place on Bunny's website.

Review attachment demo-clips.zip contains two original five-second 1280x720 QuickTime clips generated for this app, with no audio. You may also use your own MP4, MOV or M4V, including a file with audio.

Suggested review steps:
1. Import clips using the file picker or Finder drag-and-drop. Select a clip and shorten its interval in the timeline. Set speed smoothly from 0.25x to 4x; 1x resets it. Preview/export use the same speed and audio pitch changes with speed.
2. Choose an aspect ratio, move/resize the crop and select Apply to clip or Apply to all. Confirm/cancel pending crops before export. Clip/Output switches source/composed preview.
3. Export one merged MP4/MOV, then Each clip separately. The latter creates a unique subfolder with numbered final files. Remove audio produces files without an audio track.
4. Settings supports light/dark/system appearance and Czech/English/system language. About includes privacy information, the public privacy policy and MIT license.
5. Optional Bunny setup is in Settings > Bunny Storage. Enter a Storage Zone name, primary region, folder, HTTPS CDN URL and zone write password (not an account-wide API key). This optional feature requires the user's own Bunny account/credentials and is unnecessary for all local features. The password is stored in macOS Keychain and not displayed after saving.
6. After a completed local export choose Upload to Bunny.net. Review files, sizes and destination before pressing Upload. Export alone never starts networking. The HTTPS queue supports progress, cancel and retry; completed files offer copy/open CDN links. Restarted transfers wait for explicit retry. CDN visibility follows the user's Pull Zone configuration. Disconnect removes the local profile/password, not remote files; remote deletion is managed in the user's Bunny account.

The sandbox uses user-selected file access, app-scoped bookmarks for explicitly queued final exports and outgoing network access for Bunny HTTPS. No camera, microphone, screen recording, Full Disk Access or Accessibility permission is needed. Configuration, bookmarks and queue history stay local; videos remain local unless explicitly uploaded. App Privacy declares optional Photos or Videos and Audio Data for App Functionality, linked to the user's Bunny account, not used for tracking. Localio Labs receives neither the media nor the Storage Zone password.

Scope: no project save/load, public content feed, messaging or executable downloads. Target-size estimates depend on encoder overhead; lossless trims can depend on keyframes. HEVC depends on the Mac.
