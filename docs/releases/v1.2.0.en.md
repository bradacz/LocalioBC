# LocalioBC 1.2.0

- **Continuous speed control:** drag the slider from 0.25× to 4×, see the precise value, or reset to 1×. Preview and export use the same speed; audio pitch follows the speed.
- **Built-in updates:** check for updates from the application menu or Settings. You can enable daily checks and automatic downloads.
- **Keep your session safe:** installation waits while video processing is active and asks before closing in-memory edits.
- Updates and release notes are verified with an Ed25519 signature. System profiling is disabled.

Video editing and export still work offline. No videos or editing data are uploaded.

**Updating from 1.1.0 or earlier:** download and install this version manually once. Later releases can update directly in the app. The Mac App Store edition receives its updates through Apple.
