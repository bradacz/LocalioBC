# LocalioBC 1.2.0

Set the pace with a continuous speed slider and get future releases directly in the app.

## New in this release

- **Continuous speed:** drag from 0.25× to 4×, with 1× at the center, a precise readout and a one-click reset. The same speed applies to preview and export; audio pitch changes with speed.
- **Built-in updates:** optional daily checks and automatic downloads, plus **Check for Updates…** in the application menu and Settings.
- **Protected editing sessions:** installation waits for video processing and asks before closing edits held in memory.
- Signed update information and downloads, verified before extraction. System profiling is disabled; videos and edits stay on your Mac.
- A separate Store target physically excludes the updater and continues to use Apple's updates.

## Install

Download **LocalioBC-1.2.0-universal.dmg**, drag **LocalioBC.app** to **Applications** and replace your previous copy.

**If you use 1.1.0 or earlier, this first updater-enabled version must be installed manually.** Later releases can update inside the app. Automatic checks and downloads are optional.

Requires **macOS 14 or later**, on Apple Silicon or Intel. The app and DMG are Developer ID signed and Apple notarized. A SHA-256 checksum accompanies the download. Editing and export work offline; update checks require a connection.

All features in the direct edition remain free, with no accounts, subscriptions, ads or watermarks. Mac App Store distribution is a separate release channel.
