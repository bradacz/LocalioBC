# LocalioBC 1.2.1 release validation

Build 7. Release, deployment and submission checks completed on 15 November 2026 (Europe/Prague).

## Automated and native checks

- The direct target passed **38 tests with no failures**: 8 updater tests and 30 video-pipeline tests. Xcode reported `TEST SUCCEEDED`.
- Native layout checks covered Czech/light appearance at the default 1180 × 760 window size and the supported minimum editor content size of 1040 × 680, plus English/dark appearance at both sizes. Quality, target-size and lossless layouts were inspected.
- At minimum size, merged and separate target-size modes retained all controls and the full export action. A 1 MB validation warning, pending-crop message and completed-export result were visible together without sidebar scrolling.
- A merged 130-second export and a separate three-clip export completed. Export progress and completion were inspected in the native app.
- Local screenshots document these states under `dist/design-cleanup/`: `cs-minimum-completion.png`, `cs-minimum-warning-crop-result.png`, `en-dark-minimum-export.png` and `en-dark-minimum-warning-crop-result.png`. These QA artifacts are not included in the public repository.
- Runtime checks used Apple Silicon on macOS 26.5.1. Physical Intel hardware and macOS 14 were not available for runtime testing.

## Direct package and update feed
