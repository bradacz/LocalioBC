# LocalioBC 1.2.1

A cleaner export panel with every option within reach.

## Changes

- **Clean export layout:** format, compression and estimates share one continuous surface, grouped by spacing and typography. Decorative section frames, tinted backgrounds and separator lines are removed.
- **No sidebar scrolling:** export controls and the main action fit at the default and supported minimum window sizes.
- **The same export options:** merged and separate files, quality presets, target sizes, lossless export, progress, cancellation and result actions remain available.
- **Stable design rules:** the repository records the approved visual requirements and native layout checks for future changes.

## Install

Version 1.2.0 can receive this release through **Check for Updates…** in the application menu or Settings. Automatic checks and downloads are optional.

For a manual installation, use **LocalioBC-1.2.1-universal.dmg** and drag **LocalioBC.app** to **Applications**. Versions 1.1.0 and earlier require this manual step because they have no built-in updater.

Requires **macOS 14 or later**, on Apple Silicon or Intel. The direct edition remains free. The Mac App Store edition is distributed and updated separately through Apple.
