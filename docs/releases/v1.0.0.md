# LocalioBC 1.0.0

The first public release of LocalioBC: a completely free, open-source video editor for macOS.

## Download and install

- Download **LocalioBC-1.0.0-universal.dmg** below.
- Open the DMG and drag **LocalioBC.app** into **Applications**.
- Eject the disk image and launch LocalioBC from Applications.

**Requirements:** macOS 14 Sonoma or later. The same universal download supports Apple Silicon and Intel Macs.

## What's included

- Trim videos with a thumbnail timeline and precise seeking.
- Crop to common aspect ratios or a custom frame; apply the crop to one clip or all clips.
- Reorder and merge clips, or export each clip to its own numbered file.
- Export MP4/MOV with H.264/HEVC, resolution limits, quality presets and target-size estimates.
- Lossless export for eligible clips and optional audio-track removal.
- Output preview, cancellable exports and Finder integration.
- A consistent native interface, Czech and English, light/dark/system appearance and persistent preferences.

All video processing stays on your Mac. No account, subscription, ads or watermarks.

## Signing and verification

The application and disk image are signed with the **Localio Labs s.r.o. Developer ID**, notarized by Apple, and have their notarization tickets stapled. Hardened runtime is enabled. The packaged application is verified for both arm64 and x86_64 architectures.

`SHA256SUMS.txt` is included as a separate download. To verify the disk image, place both files in the same directory and run:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

The build and packaging scripts are included in the repository. Source code is available under the MIT license.

## Known limitations

- Edits are kept in memory for the current session; project save/load is not implemented.
- Target sizes are estimates and depend on encoder behavior and container overhead.
- Lossless trimming can depend on source keyframes. HEVC availability depends on the Mac.
