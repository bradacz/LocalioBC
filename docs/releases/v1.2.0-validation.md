# LocalioBC 1.2.0 release validation

Direct-download edition, build 6. Verified on 15 November 2026 (Europe/Prague).

- 38 automated tests passed, with no failures or skipped tests. Coverage includes update deferral during export/import/preview preparation, cancellation preserving the editing session, and one confirmation per approved installation.
- A Developer ID signed QA copy of the release code automatically retrieved a signed feed and downloaded a signed, notarized DMG on localhost. Only the QA bundle identity, displayed baseline version, feed URL, localhost ATS exception and corresponding sandbox service names differed from production. No QA defaults-domain override was used in the final test.
- With a synthetic clip at 1.32×, cancelling installation preserved the clip and its speed. The pending update remained available. A subsequent installation required one confirmation, restarted successfully into 1.2.0 build 6 and preserved both automatic-update preferences. A manual check then reported the current version.
- End-to-end testing found that an open Settings sheet prevented AppKit termination. Update actions now execute from the sheet's dismissal callback. Both installation and manual checks were retested through that UI.
- The app and final DMG passed Developer ID signature, notarization-ticket and Gatekeeper checks. Both arm64 and x86_64 are present. The independent App Store target also builds without Sparkle.
- Runtime tests used Apple Silicon on macOS 26.5.1. Physical Intel hardware and macOS 14 were not available for runtime testing.

Final public asset: `LocalioBC-1.2.0-universal.dmg`

SHA-256: `01803ead2b446c5872b5bddeed594f4d1803bed34552fca725488a18e79fbc40`

Version 1.1.0 and earlier must install 1.2.0 manually once; those versions contain no updater. The Mac App Store remains a separate release channel.
