# LocalioBC 1.1.0

Control the pace of every clip with the new **Speed** selector next to playback controls.

## New in this release

- Slow down or speed up each clip from **0.25× to 4×**. The chosen speed applies to both preview and export.
- Keep sound aligned with the video, including clips with silent sections. Audio pitch changes with speed.
- Export mixed-speed clips as one video or as separate numbered files.
- See the resulting duration and size estimate update with your edit. Reset to **1×** for normal speed.
- Keep the preview area stable when switching between Clip and Output.

## Download and install

Download **LocalioBC-1.1.0-universal.dmg**, open it and drag **LocalioBC.app** into **Applications**. Replace the previous copy when prompted.

**Requirements:** macOS 14 or later, Apple Silicon or Intel. All processing stays on your Mac. No account, subscriptions, ads or watermarks.

The app and disk image are Developer ID signed and notarized by Apple. Check the download with the supplied `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

This release is distributed directly. Automatic in-app updating is being designed; updating this version is a manual download and replacement. The Mac App Store submission is a separate release channel.
